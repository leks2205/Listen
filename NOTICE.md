## Programs Listen runs

Listen starts these programs but does not ship them. You install them yourself (on Windows, Listen offers to run
`winget` for you): [mpv](https://mpv.io) (GPL-2.0+/LGPL), [yt-dlp](https://github.com/yt-dlp/yt-dlp)
(Unlicense), [Deno](https://deno.com) (MIT), [whipper](https://github.com/whipper-team/whipper) (GPL-3.0) and,
when installed, [libprojectM](https://github.com/projectM-visualizer/projectm) (LGPL-2.1), which Listen loads at
run time.
